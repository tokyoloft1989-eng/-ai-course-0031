# 第一次课 复利计算器

本仓库包含课程第一课的三阶段 Python 练习和进度报告。代码由 AI 辅助生成，检查点经过本地运行验证。

## 文件

- `lesson01/step1.py`：固定参数的最小版复利计算器。
- `lesson01/step2.py`：交互输入与负利率重新输入。
- `lesson01/calculator.py`：复利与单利对比、输入校验、对齐表格。
- `lesson01/progress.md`：与课堂题面六个栏目一致的进度报告。

## 运行

使用 Python 3，在仓库根目录运行：

```sh
python3 lesson01/step1.py
python3 lesson01/step2.py
python3 lesson01/calculator.py
```

在交互版中，年利率 5% 输入 `0.05`。使用本金 `10000`、利率 `0.05`、年限 `3` 时，结果为 `11576.25`；对比表的 30 年差额为 `18219.42`。
